## 评测口径

- **返回数**：API 实际返回的实体个数（输出量）
- **期望数**：用例作者预先列出的正确答案个数（标准答案）
- **命中**：把每个期望项分到三档之一
    - `exact` ：完全相等（如 `Biden` == `Biden`）
    - `partial`：一方包含另一方（如 `President Biden` 包含 `Biden`、`济南` 被 `济南市` 包含），算半对，**仍计入 TP**
    - `miss`  ：两种都不满足
- **指标公式**
    - Precision = TP / 返回数  （模型说的话有多少是有效的）
    - Recall    = TP / 期望数  （应该说的话说了多少）
    - F1        = 2·P·R / (P+R)
